1. Таамаглал шалгах

Параметрийн аргууд (t-тест, ANOVA, шугаман регресс) өгөгдлийн талаар тодорхой таамаглал дэвшүүлдэг. Таамаглал хэр зөрчигдсөнийг график болон тестээр хамтад нь үнэлнэ.

Таамаглал Хэрхэн шалгах Зөрчигдвөл
Бие даасан байдал Судалгааны дизайнаас (давтан хэмжилт, кластер байгаа эсэх) Хамааралт тест, холимог загвар, GEE
Хэвийн тархалт Q-Q график, гистограм; Шапиро-Уилкийн тест Түүвэр том бол ихэвчлэн асуудалгүй; хувиргалт эсвэл параметрийн бус тест
Дисперсийн тэгш байдал Хайрцган график; Левенийн тест Welch t-тест / Welch ANOVA, robust SE
Шугаман хамаарал (регресс) Үлдэгдэл ба таамаг утгын график Сплайн, полином, хувиргалт
Огцом утга Хайрцган график, Cook’s distance Өгөгдлийн алдааг шалгах; огцом утгатай ба огцом утгагүй хоёр шинжилгээ хийж үр дүнгийн тогтвортой байдлыг харьцуулах 
# Хэвийн тархалт: график эхэлж, дараа нь тест
qqnorm(df$sbp8); qqline(df$sbp8)
shapiro.test(df$sbp8)

# Дисперсийн тэгш байдал
car::leveneTest(sbp8 ~ group, data = df)

# Регрессийн загварын бүх таамаглалыг нэг дор
m <- lm(sbp8 ~ group + age + sbp0, data = df)
performance::check_model(m)

Анхаар: Шапиро-Уилкийн тест том түүвэрт өчүүхэн хазайлтыг ч “ач холбогдолтой” гэж гаргадаг бол бага түүвэрт том хазайлтыг ч илрүүлэхгүй байж болно. Шийдвэрийг зөвхөн p-утгаар бус, Q-Q график болон түүврийн хэмжээг харгалзаж гаргана. Регрессэд хувьсагчийн биш, үлдэгдлийн хэвийн тархалт чухал.

2. Нөлөөний хэмжээ ба итгэх интервал

p-утга зөвхөн “тэг таамаглалтай нийцэх эсэх”-ийг хэлдэг. Ялгаа хэр том, эмнэлзүйн хувьд чухал эсэхийг нөлөөний хэмжээ ба түүний 95% итгэх интервал (CI) харуулна. Олон улсын тайлагнах заавар (CONSORT, STROBE) хоёуланг нь шаарддаг.

Арга Нөлөөний хэмжээ Бага / дунд / их (ойролцоогоор)
t-тест Дунджийн зөрүү (нэгжээр), Cohen-ийн d d: 0.2 / 0.5 / 0.8
ANOVA η², ω² 0.01 / 0.06 / 0.14
Корреляци r 0.1 / 0.3 / 0.5
Хи-квадрат (2×2) RR, OR, эрсдэлийн зөрүү Эмнэлзүйн утгаар тайлбарлана
Хи-квадрат (r×c) Cramér’s V 0.1 / 0.3 / 0.5
Манн-Уитни, Уилкоксон Rank-biserial r 0.1 / 0.3 / 0.5
Логистик регресс OR Эмнэлзүйн утгаар тайлбарлана
Пуассон регресс IRR Эмнэлзүйн утгаар тайлбарлана
Кокс регресс HR Эмнэлзүйн утгаар тайлбарлана 
effectsize::cohens_d(sbp8 ~ group, data = df)
effectsize::eta_squared(aov(sbp8 ~ city, data = df))
effectsize::interpret_cohens_d(0.45)     # "small" / "medium" ...

Жишээ: “p = 0.03” гэхийн оронд “эмийн бүлэгт систолын даралт плацебогоос 7.5 мм м.у.б-аар бага байв (95% CI 3.0; 12.0; p = 0.001)” гэж тайлагнана. CI-ийн доод хязгаар (3.0) хүртэл эмнэлзүйн ач холбогдолтой эсэхийг уншигч өөрөө дүгнэх боломжтой.

Cohen-ийн “бага/дунд/их” хил хязгаар нь ерөнхий баримжаа юм. Тухайн салбарын эмнэлзүйн хувьд ач холбогдолтой хамгийн бага ялгаа (MCID) илүү чухал.

3. Олон харьцуулалтын засвар

Олон тест хийх тусам санамсаргүйгээр “ач холбогдолтой” үр дүн гарах магадлал өснө. 20 хамааралгүй тестийг α = 0.05-аар хийвэл ядаж нэг хуурамч эерэг гарах магадлал ≈ 64%.

Арга Хэзээ R
Бонферрони Цөөн, урьдчилан төлөвлөсөн харьцуулалт. Хамгийн хатуу. p.adjust(p, "bonferroni")
Холм Бонферронигоос үргэлж илүү чадалтай, ижил хамгаалалттай. Анхдагч сонголт болгоход тохиромжтой. p.adjust(p, "holm")
Тьюки (HSD) ANOVA-гийн дараа бүх хосыг харьцуулах TukeyHSD(aov(...))
Даннет Бүх бүлгийг нэг хяналтын бүлэгтэй харьцуулах emmeans(..., trt.vs.ctrl ~ g)
Бенжамини-Хохберг (FDR) Олон зуун тест (ген, биомаркер) бүхий хайгуулын судалгаа p.adjust(p, "BH") 
p <- c(0.004, 0.019, 0.030, 0.240)
p.adjust(p, method = "holm")     # 0.016 0.057 0.060 0.240

Засвар хэзээ хэрэггүй вэ? Протоколд урьдчилан тодорхойлсон нэг гол үр дагавар ба нэг гол харьцуулалттай бол засвар шаардлагагүй. Хоёрдогч үр дагаврыг “хайгуулын” гэж тодорхой тэмдэглэн тайлагнаж болно.

4. Дутуу өгөгдөл

Анагаахын бараг бүх судалгаанд дутуу утга байдаг. Хэдэн хувь дутуу, яагаад дутуу болсон нь шинжилгээний сонголтыг тодорхойлно.

Механизм Утга Жишээ
MCAR (бүрэн санамсаргүй) Дутуу байх нь ямар ч хувьсагчаас хамаарахгүй Лабораторийн дээж санамсаргүйгээр гэмтсэн
MAR (санамсаргүй) Дутуу байх нь ажиглагдсан хувьсагчаас хамаарна Залуу хүмүүс давтан үзлэгт бага ирдэг (нас бүртгэгдсэн)
MNAR (санамсаргүй биш) Дутуу байх нь дутуу утгаасаа хамаарна Даралт нь өндөр хүмүүс үзлэгт ирэхээс зайлсхийдэг
  • Бүрэн тохиолдлын шинжилгээ (дутуутай мөрийг хасах): MCAR үед хазайлтгүй, гэхдээ чадал буурна. Бусад үед хазайлттай байж болно.
  • Олон дахин нөхөх (multiple imputation): MAR үед санал болгох арга. Дутуу утгыг олон удаа нөхөж, үр дүнг нэгтгэнэ.
  • Холимог загвар: давтан хэмжилтэд MAR үед дутуу хэмжилттэй хүмүүсийг хасалгүй ашиглана.
  • Дунджаар нөхөх, сүүлийн утгыг үргэлжлүүлэх (LOCF) аргыг ерөнхийдөө хэрэглэхгүй.
# Хувьсагч бүрийн дутуу хувь
colMeans(is.na(df)) * 100
naniar::vis_miss(df)

# Олон дахин нөхөх
library(mice)
imp <- mice(df, m = 20, seed = 2026)
fit <- with(imp, lm(sbp8 ~ group + age + sbp0))
summary(pool(fit), conf.int = TRUE)

Тайлагнахдаа хувьсагч бүрийн дутуу хувь, шинжилгээнд орсон хүний тоо, дутуу өгөгдөлтэй хэрхэн ажилласнаа заавал бичнэ.

5. Жишээ өгөгдөл

Сайтын кодыг өөрийн компьютер дээр туршихад зориулсан зохиомол өгөгдөл: 200 өвчтөн, эм ба плацебо бүлэг.

emnelgiin-jishee.csv татах
Хувьсагч Тайлбар Тохирох аргууд
id Өвчтөний дугаар
group Эм / Плацебо t-тест, хи-квадрат, регресс
sex, age, bmi, smoker Хүйс, нас, БЖИ, тамхи татдаг эсэх Ковариат
city Улаанбаатар / Эрдэнэт / Дархан ANOVA, Крускал-Валлис
sbp0, sbp8 Систолын даралт: эхэнд ба 8 дахь долоо хоногт (мм м.у.б) Хамааралт t-тест, ANCOVA
pain0, pain6 Өвдөлтийн оноо (0–10): эхэнд ба 6 дахь долоо хоногт Уилкоксон, Манн-Уитни
infection Хүндрэлийн халдвар (Тийм / Үгүй) Хи-квадрат, логистик регресс
ari, years Амьсгалын замын халдварын тоо, ажигласан жил Пуассон / сөрөг биномын регресс
time_months, event Ажигласан хугацаа (сар), үйл явдал (1 = тохиолдсон, 0 = цензур) Каплан-Майер, Кокс регресс 
df <- read.csv("emnelgiin-jishee.csv", encoding = "UTF-8")
str(df)

t.test(sbp8 ~ group, data = df)
chisq.test(table(df$group, df$infection))
summary(MASS::glm.nb(ari ~ city + smoker + offset(log(years)), data = df))
survival::coxph(survival::Surv(time_months, event) ~ group + age, data = df)
